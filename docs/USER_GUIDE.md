# 사용자 가이드

> 프로그램 사용법 따라하기

## 기본 사용법

### 1단계: 프로그램 실행

```bash
cd src
python main.py
```

GUI 창이 뜨면 준비 완료.

### 2단계: 파일 선택

**원시 데이터 파일**
- 출근기록기에서 뽑은 Excel 파일
- 예: `1.21.xlsx`, `근태데이터_20260121.xlsx`
- .xls, .xlsx 둘 다 됨

**여주 근태표 파일**
- 일일근태보고-여주(202601).xlsx
- 월별 파일

**SMC 근태표 파일**
- 일일근태보고-SMC(202601).xlsx
- 월별 파일

각 파일 옆 "찾아보기" 버튼 클릭해서 선택.

### 3단계: 기준 날짜 입력

**형식**: `YYYY-MM-DD`

**중요**: 원시 데이터 파일에 포함된 **가장 최근 날짜**를 입력해야 함!

**예시**:
- 파일명: `1.21.xlsx`
- 기준 날짜: `2026-01-21` 입력

**주의사항**:
- 오늘 날짜(`date.today()`) 아님!
- 파일에 없는 날짜 입력하면 데이터 입력 0건 나옴
- 로그에서 "오늘 맵: 0명" 나오면 날짜 잘못 입력한 거임

### 4단계: 실행

"실행" 버튼 클릭.

프로그램이 알아서:
1. 원시 데이터 로드
2. 패턴 분석 (공휴일 감지 등)
3. 데이터 검증
4. 출퇴근 맵 생성
5. 근태표에 입력
6. 잔업 시간 계산 및 기록

로그 창에서 진행 상황 확인 가능.

### 5단계: 결과 확인

#### 정상 처리
```
[SUCCESS] 출퇴근 데이터 입력 완료
[INFO]   처리: 55명
[INFO]   입력: 76건
[INFO]   잔업: 7건
```

- 근태표 파일 열어서 확인
- 잔업_기록.xlsx 파일 확인

#### 문제 데이터 발견
```
[WARNING] 문제 데이터 31건 발견
[INFO] 파일 생성: 문제_데이터_확인.xlsx
```

문제 데이터 처리 필요 (아래 참조)

## 문제 데이터 처리

### 문제 유형

1. **출근만 있음 (퇴근 누락)**
   - 출근 찍었는데 퇴근 안 찍음
   - 퇴근 시간 수동 입력 필요

2. **퇴근만 있음 (출근 누락)**
   - 출근 안 찍고 퇴근만 찍음
   - 출근 시간 수동 입력 필요

3. **시간 형식 오류**
   - "8시" 같은 이상한 형식
   - 올바른 형식으로 수정 필요

4. **퇴근이 출근보다 빠름**
   - 말이 안 되는 시간
   - 데이터 확인 후 수정

### 처리 방법

1. **문제_데이터_확인.xlsx** 파일 열기

2. 파일 구조:
   ```
   | 이름   | 날짜       | 문제            | 원본_출근 | 원본_퇴근 | 수정_출근 | 수정_퇴근 |
   |--------|------------|-----------------|-----------|-----------|-----------|-----------|
   | 홍길동 | 2026-01-21 | 출근만 있음     | 08:30:00  |           |           | 17:40:00  |
   | 김철수 | 2026-01-21 | 시간 형식 오류  | 8시       | 18:00:00  | 08:00:00  |           |
   ```

3. **수정_출근** 또는 **수정_퇴근** 컬럼에 올바른 시간 입력
   - 형식: `HH:MM` 또는 `HH:MM:SS`
   - 예: `08:30`, `17:40:00`

4. 파일 저장

5. 프로그램에서 **"재입력"** 버튼 클릭

6. 문제 데이터만 다시 처리됨

## 출퇴근 패턴 설명

프로그램이 자동으로 감지하는 12가지 패턴:

### 주간 근무 패턴

**1. today_complete** - 오늘 출퇴근 완료
- 오늘 출근 ✓, 오늘 퇴근 ✓
- 예: 출근 08:30, 퇴근 17:40

**2. today_checkin_only** - 오늘 출근만
- 오늘 출근 ✓, 오늘 퇴근 ✗
- 퇴근 기록 대기 중

**3. checkout_only** - 퇴근만
- 오늘 출근 ✗, 오늘 퇴근 ✓
- 이상한 경우 (출근 누락)

**4. today_checkin_with_prev_checkout** - 오늘 출근 + 전날 퇴근
- 오늘 출근 ✓, 전날 퇴근 ✓
- 가장 흔한 패턴 (전날 잔업했을 때)
- 예: 전날 출근 08:30 → 전날 퇴근 20:55
      오늘 출근 08:23

### 야간 근무 패턴

**5. night_shift** - 야간 근무
- 오늘 출근(야간) ✓, 오늘 퇴근 ✓
- 예: 출근 20:30, 퇴근 05:40 (다음날)

**6. prev_night_shift_complete** - 전날 야간 완료
- 오늘 데이터 없음, 전날 야간 근무
- 예: 전날 출근 20:30 → 오늘 퇴근 05:40

**7. night_shift_checkin_only** - 야간 출근만
- 오늘 출근(야간) ✓, 퇴근 대기
- 예: 출근 20:30만 있음

### 기타 패턴

**8. absent_with_prev_checkout** - 결근 + 전날 퇴근
- 오늘 데이터 없음, 전날 퇴근만 있음

**9~12. 기타 엣지 케이스**
- 잘 안 나오는 특수한 경우들

자세한 패턴 설명: [COMPLETE_DOCUMENTATION.md](COMPLETE_DOCUMENTATION.md)

## 잔업 기능 사용

### 자동 계산

프로그램이 자동으로 잔업 계산:
- 주간: 17:40 이후 퇴근
- 야간: 05:40 이후 퇴근

로그에서 확인:
```
[INFO]   채진성: 출근=08:23, 퇴근=20:55, 잔업=2.4시간
[INFO]   이민호: 출근=08:10, 퇴근=19:09, 잔업=1.0시간
```

### 직원 유형 설정

**employee_config.json** 파일 생성/수정:
```json
{
  "채진성": "NORMAL",
  "이민호": "MANAGER",
  "김철수": "SMT"
}
```

유형:
- `NORMAL`: 일반 직원
- `MANAGER`: 관리자 (일반과 동일 테이블)
- `SMT`: SMT/자체영업부 (확장 테이블)

설정 안 하면 기본값 NORMAL 적용.

### 잔업 기록 확인

**잔업_기록.xlsx** 파일 자동 생성:

| 이름   | 날짜       | 직원유형 | 근무유형 | 정규퇴근 | 실제퇴근 | 잔업시간 | 석식제공 |
|--------|------------|----------|----------|----------|----------|----------|----------|
| 채진성 | 2026-01-20 | 일반직원 | 주간     | 17:40    | 20:55    | 2.4      | X        |
| 이민호 | 2026-01-20 | 관리자   | 주간     | 17:40    | 19:09    | 1.0      | X        |

## 고급 설정

### config.py 수정

**공휴일 감지 임계값**
```python
HOLIDAY_THRESHOLD = 0.3  # 평균 출근의 30%
MIN_ATTENDANCE = 5       # 최소 출근 인원
```

**블록 설정**
```python
YEOJU_BLOCKS = [
    ("C9:C11", "D9:D11", "E9:E11", "G9:G11"),  # 경영지원팀
    ...
]
```

**잔업 테이블**
```python
OVERTIME_TABLE_NORMAL = [
    ("18:10", 0.5, False),  # 시간, 잔업시간, 석식제공
    ("18:40", 1.0, False),
    ...
]
```

## 팁 & 트릭

### 빠른 재실행
- 문제 수정 후 "재입력" 버튼으로 빠르게 재처리
- 전체 다시 실행할 필요 없음

### 로그 확인
- DEBUG 모드에서 상세 로그 출력
- 문제 발생 시 로그 확인하면 원인 파악 쉬움

### 파일 백업
- Excel 파일 항상 백업 추천
- 프로그램이 원본 수정함

### 여러 날짜 한번에
- 현재는 하루씩만 처리
- 여러 날 처리하려면 반복 실행

### 디버깅
```python
# logger.py에서 로그 레벨 변경
LOG_LEVEL = "DEBUG"  # 상세 로그
LOG_LEVEL = "INFO"   # 기본 로그
```

## 자주 묻는 질문 (FAQ)

**Q: 기준 날짜를 오늘로 하면 안됨?**
A: 안됨. 파일에 있는 날짜 입력해야 함.

**Q: .xls 파일 안 읽힘**
A: `pip install xlrd==2.0.1`

**Q: 야간 근무자 잔업 안 나옴**
A: v3.0에서 수정됨. 최신 버전 확인.

**Q: Excel이 이미 열려있으면?**
A: 닫고 실행. COM 충돌 방지.

**Q: 잔업 테이블 수정하고 싶음**
A: config.py에서 OVERTIME_TABLE_XXX 수정.

**Q: 직원 유형 일괄 변경**
A: employee_config.json 파일 수동 편집.

**Q: 공휴일이 잘못 감지됨**
A: config.py에서 HOLIDAY_THRESHOLD 조정.

**Q: 프로그램이 느림**
A: Excel COM이 원래 느림. 기다리면 됨.
