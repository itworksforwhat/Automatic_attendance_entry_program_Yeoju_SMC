# 잔업 시간 추적 시스템 가이드

## 📋 개요

근태 자동 입력 프로그램 v4.0에서는 잔업 시간 기록 및 관리 기능이 추가되었습니다.

## 🆕 주요 기능

1. **자동 잔업 시간 계산**: 정규 근무 시간 초과 시 자동으로 잔업 시간 계산
2. **근태표에 자동 기록**: 계산된 잔업 시간이 여주/SMC 근태표에 자동으로 입력됨
3. **직원 유형별 가중치**: 일반 직원, 관리자, SMT/자체영업부별 다른 잔업 테이블 적용
4. **석식 제공 여부 추적**: 시간대에 따른 석식 제공 여부 자동 기록
5. **Excel 파일로 추가 저장**: 잔업 기록이 `잔업_기록.xlsx` 파일로도 별도 저장

## ⚙️ 설정

### 1. 정규 근무 시간

`config.py`에 정의되어 있습니다:

```python
# 주간 근무: 08:30 ~ 17:40
DAY_SHIFT_START = "08:30"
DAY_SHIFT_END = "17:40"

# 야간 근무: 20:30 ~ 05:40
NIGHT_SHIFT_START = "20:30"
NIGHT_SHIFT_END = "05:40"
```

### 3. 직원 유형 설정

직원의 유형(일반/관리자/SMT)을 설정하는 방법:

#### 방법 1: employee_config.json 파일 직접 편집

프로그램 실행 디렉토리에 `employee_config.json` 파일을 생성하고 다음 형식으로 작성:

```json
{
  "홍길동": "NORMAL",
  "김철수": "MANAGER",
  "이영희": "SMT",
  "박민수": "SMT"
}
```

**직원 유형 코드:**
- `NORMAL`: 일반 직원
- `MANAGER`: 관리자
- `SMT`: SMT/자체영업부

#### 방법 2: Python 코드로 설정

```python
from employee_manager import EmployeeManager
from models import EmployeeType

manager = EmployeeManager()

# 개별 설정
manager.set_employee_type("홍길동", EmployeeType.NORMAL)
manager.set_employee_type("김철수", EmployeeType.MANAGER)
manager.set_employee_type("이영희", EmployeeType.SMT)

# 일괄 설정
employees = {
    "홍길동": EmployeeType.NORMAL,
    "김철수": EmployeeType.MANAGER,
    "이영희": EmployeeType.SMT,
}
manager.set_multiple_employees(employees)
```

## 📊 출력 위치

### 1. 근태표 내 잔업시간 컬럼

여주/SMC 근태표의 각 팀 블록에서 **가장 오른쪽 컬럼**에 잔업시간이 자동으로 기록됩니다.

**예시 (경영지원팀):**
- C열: 이름
- D열: 출근시간
- E열: 퇴근시간
- F열: (기타)
- **G열: 잔업시간** ← 자동으로 계산되어 입력됨

**처리 방식:**
1. 매일 잔업시간 셀을 초기화 (CLEAR_RANGES)
2. 새로 계산된 잔업시간을 기록
3. 잔업이 없으면 빈 칸으로 유지

### 2. 잔업_기록.xlsx (별도 파일)

프로그램 실행 후 자동으로 생성되는 Excel 파일로, 다음 정보가 포함됩니다:

| 컬럼명 | 설명 |
|--------|------|
| 이름 | 직원 이름 |
| 날짜 | 근무 날짜 |
| 직원유형 | 일반직원/관리자/SMT/자체영업부 |
| 근무유형 | 주간/야간 |
| 정규종료 | 정규 근무 종료 시간 |
| 실제퇴근 | 실제 퇴근 시간 |
| 잔업시간 | 인정된 잔업 시간 |
| 석식제공 | 석식 제공 여부 (O/X) |

## 🔍 잔업 계산 로직

### 주간 근무자 (08:30~17:40)

1. 퇴근 시간이 17:40 이전 → 잔업 없음
2. 퇴근 시간이 17:40 이후 → 잔업 테이블에서 해당 시간대 찾기
3. 중간 시간 (예: 18:25) → **이전 시간대** 적용 (18:10 = 0.5시간)

### 야간 근무자 (20:30~05:40)

1. 퇴근 시간이 05:40 이전 → 잔업 없음
2. 퇴근 시간이 05:40 이후 → 동일한 잔업 테이블 적용

### 평일만 처리

- 현재 버전에서는 **평일**만 잔업을 계산합니다
- 공휴일과 주말은 잔업 계산에서 제외됩니다

### 시나리오 3: 야간 근무자

- **이름**: 김철수 (야간 근무)

- **결과**: 잔업 0.5시간 (야간 테이블 적용)

## 🛠️ 설정 파일 수정

잔업 테이블이나 정규 근무 시간을 변경하려면:

1. `attendance_v3/config.py` 파일 열기
2. 해당 설정 수정:
   - `DAY_SHIFT_START`, `DAY_SHIFT_END`: 주간 근무 시간
   - `NIGHT_SHIFT_START`, `NIGHT_SHIFT_END`: 야간 근무 시간
   - `OVERTIME_TABLE_NORMAL`: 일반/관리자 잔업 테이블
   - `OVERTIME_TABLE_SMT`: SMT 잔업 테이블
3. 프로그램 재실행

## ⚠️ 주의사항

1. **직원 유형 미설정 시**: 기본값으로 "일반 직원" 테이블이 적용됩니다
2. **잔업 파일 덮어쓰기**: 매 실행마다 `잔업_기록.xlsx` 파일이 새로 생성됩니다
3. **평일만 기록**: 공휴일/주말은 자동으로 제외됩니다
4. **시간 매칭 규칙**: 퇴근 시간이 테이블 중간값일 때는 이전 시간대가 적용됩니다
