# 여주SMC 근태 자동 입력 v3.0

> **일하기 싫어서 만든 간이 툴**
> 매일 손으로 하던 근태 입력을 자동화한 개인 프로젝트

## 🎯 이게 뭐임?

매일 아침 Excel 파일 열어서 출퇴근 시간 복붙하는 거 귀찮아서 만든 프로그램.
원시 데이터만 주면 알아서 근태표에 입력해줌.

### 주요 기능
- ✅ 출퇴근 데이터 자동 입력
- ✅ **잔업 시간 자동 계산** (NEW!)
- ✅ 공휴일 자동 감지 (출근 인원으로 판단)
- ✅ 야간 근무 자동 처리
- ✅ 문제 데이터 자동 찾아서 알려줌

## 📦 설치

### 요구사항
- Python 3.8 이상
- Excel (COM 쓰려면 필요)
- Windows (맥은 안됨)

### 설치 방법
```bash
cd src
pip install -r requirements.txt
python main.py
```

## 🚀 사용법

### 1. 프로그램 실행
```bash
python src/main.py
```

### 2. 파일 선택
- **원시 데이터**: 1.21.xlsx 같은 파일
- **여주 근태표**: 일일근태보고-여주(202601).xlsx
- **SMC 근태표**: 일일근태보고-SMC(202601).xlsx

### 3. 기준 날짜 입력
- 형식: `YYYY-MM-DD`
- 예: `2026-01-21`
- ⚠️ **중요**: 원시 데이터 파일에 있는 가장 최근 날짜를 입력해야 함

### 4. 실행 클릭
- 끝. 알아서 다 함

### 5. 문제 데이터 있으면
- `문제_데이터_확인.xlsx` 파일이 생성됨
- 수정_출근, 수정_퇴근 컬럼 수정하고 저장
- "재입력" 버튼 클릭

## 💡 새로 추가된 기능 (v3.0)

### ⏰ 잔업 시간 자동 계산
더 이상 잔업 시간 계산 안 해도 됨. 프로그램이 알아서 계산해줌.

**주간 근무** (08:30 ~ 17:40)
- 17:40 이후 퇴근하면 잔업 인정
- 18:10부터 0.5시간씩 증가

**야간 근무** (20:30 ~ 05:40)
- 05:40 이후 퇴근하면 잔업 인정
- 주간이랑 동일한 테이블 사용 (시간 환산해서)

**직원 유형별 차등**
- 일반직원/관리자: 기본 테이블
- SMT/자체영업부: 확장 테이블 (석식 제공 포함)

**결과물**
- 근태표에 잔업 시간 자동 입력
- `잔업_기록.xlsx` 파일 자동 생성

자세한 내용: [docs/OVERTIME.md](docs/OVERTIME.md)

## 🔍 어떻게 작동함?

### 1단계: 데이터 읽기
- Excel 파일 열어서 출퇴근 시간 읽음
- 이상한 형식도 알아서 파싱함

### 2단계: 패턴 분석
- 출근 인원 보고 공휴일 자동 감지
- 이전 근무일 자동 찾기

### 3단계: 데이터 검증
- 출근만 있거나 퇴근만 있으면 문제로 분류
- 시간 이상하면 문제로 분류

### 4단계: 출퇴근 입력
- 12가지 패턴 중에 맞는 거 찾아서 입력
- 야간 근무도 자동으로 처리

### 5단계: 잔업 계산 (NEW!)
- 정규 시간 이후 퇴근하면 잔업 계산
- 잔업 시간 근태표에 입력
- 잔업_기록.xlsx 파일에 기록

### 6단계: 문제 데이터 처리
- 문제 있으면 Excel 파일로 저장
- 수정하고 재입력하면 됨

## 🐛 문제 해결

### "pywin32를 찾을 수 없습니다"
```bash
pip install --upgrade pywin32
```

### "Excel을 열 수 없습니다"
- Excel 설치되어 있는지 확인
- 관리자 권한으로 실행

### "기준 날짜: 2026-01-22" 인데 데이터 입력이 0건
- GUI에서 기준 날짜를 파일에 있는 날짜로 바꿔야 함
- 예: 1.21.xlsx 파일이면 기준 날짜를 2026-01-21로 입력

### 야간 근무자 잔업이 계산 안됨
- 이제 수정됨 (v3.0)
